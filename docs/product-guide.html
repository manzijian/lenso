LENSO 产品功能说明

面向产品评审、演示与交付验收，逐屏说明当前 macOS 原生应用的界面布局、具体操作步骤与操作结果。全文以仓库当前 Swift 源码为准，界面语言为简体中文。

平台 macOS 26 形态 菜单栏常驻应用 范围 11 个界面 / 浮层 基准 dcd0118

一页看懂产品闭环

从菜单栏或快捷键发起截图 → 拖拽选区 / 单击吸附窗口 → 在冻结画面上调整选区并标注 → 保存、复制或钉在屏幕上；截图进入图库，可通过搜索或预览取回。应用启动时自动监听剪贴板，把复制过的图片与文字存入剪贴板历史，并将文字同步收纳。

01 / OVERVIEW

产品总览与任务速查

LENSO 是常驻系统菜单栏的截图与剪贴板资料工具。应用关闭最后一个窗口后仍继续运行，启动时自动开启剪贴板监听。当前实现由 11 个原生界面 / 浮层构成，统一使用浅色外观与蓝紫色玻璃质感。

02 / MENU BAR

菜单栏快捷面板

点击系统菜单栏中的 LENSO 取景器图标，打开横向排列的四个快捷入口。面板由系统管理，宽 312pt，使用浅色玻璃容器；每个入口为 64 × 82pt 的图标与文字组合，悬停时图标底色变为系统强调色。

四个入口从左到右依次为「截图」「图库」「搜索」「设置」；示意图仅表达结构。

布局说明

面板主体为水平等距排列的四个玻璃效果入口，每个入口上方是 52 × 52pt 圆角图标，下方是 11pt 标签。点击任一入口执行动作后立即收起面板。「图库」「设置」打开单实例窗口并激活应用；「搜索」显示浮动面板；「截图」启动截图链路。

操作步骤

  1. 打开面板：点击系统菜单栏右上区域的 LENSO 取景器图标。
  2. 悬停确认：将指针移到目标入口，图标底色会高亮。
  3. 单击执行：按需点击「截图」「图库」「搜索」或「设置」；面板随即关闭，对应窗口 / 浮层出现在屏幕上。
  4. 重复打开窗口：再次点击「图库」或「设置」只会聚焦已有窗口，不会叠开第二个同类型窗口。

布局说明

每块浮层由三层组成：冻结屏幕图、黑色遮罩与选区挖空层、选区尺寸标签。选区使用白色细描边；窗口吸附候选区用蓝色描边。首次使用截图能力时，macOS 会要求「屏幕录制」权限；未获授权时仅发出提示音，应用内没有授权引导弹窗。

操作步骤

  1. 发起：点击菜单栏「截图」，或在前台按 ⇧⌘1；若系统首次弹出权限请求，先完成授权。
  2. 框选：在冻结画面上按住鼠标并拖拽，观察白色边框与「宽 × 高」实时数字，松开鼠标确认。
  3. 或吸附窗口：移动指针到目标窗口，出现蓝色高亮后单次单击（指针移动小于 4pt），直接选中整个窗口。
  4. 取消：按 Esc 退出，不进入编辑器。

结果与状态

有效选区小于 8 × 8pt 的拖拽会被丢弃；有效选区进入标注编辑器，并成为初始裁剪范围。
多显示器每个屏幕各有一块浮层；实际截图使用鼠标按下所在屏幕的显示器 ID。
权限未通过不显示选区浮层，仅有提示音；需到 macOS 系统设置中开启屏幕录制后重试。

底部工具栏位于选区下方并始终收在屏幕内；右侧属性面板贴着选区右边、垂直居中，超出屏幕时自动向内收。

布局说明

编辑器以冻结画面为底，上覆 30% 黑色遮罩、选区挖空区域、8 个白色缩放把手和标注画布。底部 720 × 52pt 胶囊工具栏从左至右为：选择箭头，七种标注工具（矩形、椭圆、箭头、画笔、文字、马赛克、高亮），撤销 / 重做，图钉，「完成」与「取消截图（Esc）」图标。

右侧 252 × 470pt 玻璃属性面板依次为：「标注 / 翻译 / OCR / 更多」、7 色色盘、1—10px 粗细滑杆、5 个形状快捷方式、「马赛克」「高亮」开关以及「复制到剪贴板」按钮。默认颜色为蓝色、粗细 2px、选择箭头激活。

再点一次当前工具可取消选中；「马赛克」「高亮」工具与右侧同名开关会互相影响激活状态。标注坐标按选区比例保存，因此缩放选区时标注会随之变化。

操作步骤

  1. 调整范围：未选标注工具时，拖拽选区内部可整体移动；拖拽四角或四边的白色把手可缩放范围。
  2. 设置样式：在右侧属性面板点选 7 色之一，拖动 1—10px 滑杆设置粗细；也可用形状快捷行切换工具，或打开「马赛克」「高亮」开关。
  3. 绘制标注：点底部工具图标，在选区内按住并拖拽出起点与终点，松开后生成一条标注；继续拖拽可叠加多个标注。
  4. 撤销 / 重做：点底部左弯箭头撤销，或点右弯箭头重做；按钮在无可撤销 / 重做内容时置灰。
  5. 选择结果：点「完成」保存；点右侧「复制到剪贴板」只复制；点图钉「钉在屏幕上」生成浮窗；点「✕」或按 Esc 丢弃。

05 / FEEDBACK

保存 / 操作提示

保存、复制和收藏操作使用同一个轻量提示浮层：主屏幕右下角、距边缘 24pt、尺寸 300 × 64pt，不抢焦点，自动淡入、停留与淡出。

                                      主屏幕右下角
                              ┌──────────────────────────────┐
                              │ ✓  截图已保存        [缩略图] │
                              │    到图片库                  │
                              └──────────────────────────────┘
                                 绿色勾 · 标题 · 副标题 · 可选图
显示时长
淡入 0.25 秒 → 停留 2.6 秒 → 淡出 0.3 秒新提示会取消上一条的隐藏计时。
内容结构
绿色勾选图标 + 主标题 + 副标题 + 可选 40 × 30pt 缩略图浅色圆角卡片，无按钮，不响应点击。

操作步骤与触发结果

  1. 保存截图：编辑器点「完成」；出现「截图已保存 / 到图片库」。
  2. 复制截图 / 文字：从搜索结果、剪贴板历史、文字收纳复制内容；出现「已复制 / 到剪贴板」。
  3. 收藏文字：在剪贴板历史点书签；出现「已收藏 / 到文字收纳」。
  4. 等待消失：无需手动关闭，提示会自动淡出。
源码依据：LENSO/Application/SaveToast.swift:10-104；文案调用见 LENSO/Search/SearchPanelView.swift:163、LENSO/Clipboard/ClipboardPanelView.swift:172, 185、LENSO/TextNotes/TextNotesView.swift:149。

13 / SCOPE

当前实现边界

下列项目用于避免评审时把「已绘制的控件」误认为「已接通的能力」。它们不属于本版可交付的操作步骤，也不来自规划文档或 HTML 视觉 Demo。

区域当前边界
设置所有开关使用固定值，点击不会改变配置，也没有设置持久化；显示「跟随系统外观」，但应用实际强制浅色外观。「快捷键」页仅展示两项，未列出全部菜单命令。
标注编辑器「翻译」「OCR」「更多」按钮无动作；「画笔」为单条直线而非自由笔迹；「文字」不接受文字输入，导出为半透明黄色矩形；「⌘C」只是按钮上的提示文字，没有注册对应快捷键。
编辑器快速复制点「复制到剪贴板」不会保存截图，但复用的提示文案仍为「截图已保存 / 到图片库」。
图库「最近」「收藏」「回收站」、标签项及计数，网格 / 列表切换、「全部时间 ▾」、省略号、底部分享 / 删除 / 更多图标均为展示型控件；底部选中大小按每张约 2.3 MB 估算。当前界面没有接通批量删除或复制。
预览裁剪、返回、标注、取色图标无动作；预览窗口没有复制或删除按钮。
