Keynote — LENSO 发布会初稿
… 首发支持简体中文与英文界面，OCR 识别语言跟随系统…
11 月 2 日 10:26 · Keynote · 标签：会议记录
简体中文 · 置信度 96%

项目技术目标：LENSO 是一款 macOS 原生智能截图工具，

以「截得快、找得到」为核心体验。系统级快捷键触发截屏，

截图自动进入时间轴图库，并通过 OCR 建立全文索引。

核心能力：毫秒级区域截屏；OCR 文字识别支持简体中文、

英文与混排内容；按来源应用自动归类，支持自定义标签；

本地全文检索可在 200ms 内返回结果，全程数据不出设备。

翻译 英 → 中

Project goals: LENSO is a native macOS smart screenshot tool built around "capture fast, find fast". System-wide hotkeys trigger captures, which flow into a timeline library with full-text OCR indexing.
